# 🌐 Personal Website — Dwifa Nusa Rahmani

Selamat datang di **Personal Website Dwifa Nusa Rahmani**.

Website ini dibuat sebagai proyek latihan untuk mempelajari dasar-dasar **HTML dan CSS**, sekaligus sebagai media untuk memperkenalkan profil, pendidikan, hobi, dan proyek yang sedang dikerjakan.

## 👩‍💻 Tentang Saya

**Dwifa Nusa Rahmani** adalah mahasiswa Program Studi **Pendidikan Sistem dan Teknologi Informasi (PSTI)** yang memiliki ketertarikan pada bidang **Web Development** dan teknologi informasi.

Saya mulai mempelajari pembuatan website dari dasar menggunakan HTML. Target saya adalah dapat membuat website yang **bermanfaat, menarik, dan mudah digunakan**.

## 📌 Fitur Website

Website ini terdiri dari beberapa halaman:

* 🏠 **Home** — Halaman utama website.
* 👤 **About** — Berisi profil singkat, data diri, hobi, dan riwayat pendidikan.
* 💻 **Projek** — Berisi informasi mengenai proyek yang sedang atau telah dibuat.
* 📩 **Kontak** — Halaman untuk informasi kontak.

## 🛠️ Teknologi yang Digunakan

## 🚀 Cara Menjalankan

1. Clone repository ini:

```bash

```

2. Masuk ke folder project:

```bash
cd personal-website
```

3. Buka file `home.html` atau `index.html` menggunakan browser.
